# BugLoop 前端页面 Spec

> 本文件的核心职责：定义一期页面结构、交互行为以及不同 Bug 状态下允许展示的操作。章节编号沿用 `BugLoop_SPEC_v1.0` 原编号，便于追溯。

## 五十二、前端页面 Spec

### 52.1 登录页

字段：

```Plain
用户名
密码
```

成功登录后：

- 如果只有一个工作空间，直接进入；
- 如果有多个工作空间，进入最近使用工作空间；
- 如果没有工作空间，进入“创建 / 加入工作空间”的空状态页。

### 52.2 顶部工作空间切换

页面顶部始终显示当前 Workspace。

点击后显示：

```Plain
当前用户加入的工作空间
+
创建工作空间
```

创建工作空间入口只对 `SYSTEM_ADMIN` 或已在任一工作空间担任 `OWNER / ADMIN` 的用户显示；
其他用户看到的是提示联系管理员创建或邀请加入的文案，与后端 47.1 的创建权限保持一致。
没有工作空间且无创建权限的用户，登录后停留在空状态页并显示同样的提示。

切换 Workspace 后：

- Bug 列表刷新；
- 我的 Bug 刷新；
- 成员列表刷新；
- URL 或前端 Store 中更新 workspaceId。

### 52.3 首页

一期首页保持简单。

显示：

```Plain
我的待处理
我的处理中
待我验收
最近更新Bug
```

不建设复杂 BI Dashboard。

### 52.4 Bug 列表

表格列：

```Plain
Bug编号
标题
优先级
状态
负责人
提交人
验收人
创建时间
更新时间
```

筛选：

```Plain
关键字
状态
优先级
负责人
提交人
时间范围
```

默认：

```Plain
20条 / 页
updatedAt DESC
```

筛选条件显示：

- 关键字按编号和标题模糊匹配（大小写不敏感、匹配任意片段），输入停顿后自动查询，回车立即查询
- 列表、我提交的、指派给我的、待我验收等入口共用同一张列表；进入任一入口都先重置筛选，再应用该入口的预置条件（如待我验收 = 验收人当前用户 + 状态待验收），避免沿用上一个入口的条件
- 默认全部展开；关键字搜索始终显示
- 筛选面板右上角提供「收起筛选 / 展开筛选」按钮，收起后筛选区整体隐藏、只保留列表清单，已选条件与查询结果保持不变
- 「筛选条件」菜单可逐项勾选或取消，也可用「全部显示」总开关一键全部显示 / 全部隐藏
- 隐藏一个已生效的筛选条件时同时清除其查询值，避免条件生效但界面不可见
- 显示设置按用户保存在本地，重置筛选后恢复默认的全部展开

### 52.5 创建 Bug 页面

字段顺序建议：

```Plain
标题 *
详细说明 Markdown *
优先级
负责人
验收人
附件
```

默认：

```Plain
priority = P2
acceptor = currentUser
```

### 52.6 Bug 详情页

页面结构：

```Plain
顶部：
BUG编号 / 标题 / 状态 / 优先级 / 负责人 / 验收人

主体：
问题描述
附件
修复说明
验收记录
评论
操作日志
文档历史
```

顶部根据状态显示业务按钮。

#### TODO

当前负责人看到：

```Plain
开始处理
```

OWNER / ADMIN 看到：

```Plain
指派
修改验收人
```

#### PROCESSING

当前负责人看到：

```Plain
编辑修复说明
提交验收
```

#### WAIT_ACCEPTANCE

当前验收人看到：

```Plain
验收通过
验收驳回
```

#### REOPENED

当前负责人看到：

```Plain
开始处理
```

#### CLOSED

不显示任何状态操作按钮。

只保留查看、评论。

### 52.6.1 详情交互方式

列表页点击 Bug 行时，在当前列表路由上以查询参数打开右侧非模态详情抽屉：

```Plain
/workspaces/{workspaceId}/bugs?bugId={bugId}
```

要求：

- 打开抽屉不丢失列表筛选条件与滚动位置；关闭后回到原列表状态
- 查询参数与浏览器前进 / 后退同步，返回键等同于关闭抽屉
- 抽屉内复用完整详情能力，并提供「在独立页面打开」入口跳转到
  `/workspaces/{workspaceId}/bugs/{bugId}`，适用于需要更宽编辑空间的场景
- 创建成功后进入独立详情页

### 52.7 成员管理

OWNER / ADMIN 可操作：

```Plain
添加成员
移除成员
调整角色
```

普通 MEMBER：

> 只读成员列表。

### 52.7.1 系统用户管理

仅 `SYSTEM_ADMIN` 在工作空间侧边栏看到“用户管理”入口。页面展示系统用户列表，并提供创建普通用户
弹窗；创建成功后刷新列表，但不得切换管理员当前登录身份。普通用户即使直接访问路由，也应被路由守卫
重定向，最终权限仍由后端接口校验。

### 52.8 工作空间设置

OWNER 可以：

```Plain
修改名称
修改说明
停用工作空间
重新启用已停用工作空间
```

ADMIN：

```Plain
可以修改名称和说明
不能停用或重新启用
```

导航：

```Plain
顶部导航在设置页显示「返回 Bug 列表」，其余页面显示「工作空间设置」
```

### 52.9 操作提示

列表、创建和详情页的操作错误统一用居中浮层提示：

- 固定展示在当前视口中央，长页面滚动后仍然可见，不随页面滚动隐藏
- 展示 3 秒后淡出消失（渐隐动画），也可点击关闭按钮立即关闭；无遮罩层，不影响页面其余区域的交互
- 校验失败（如空评论、附件超限）在发起请求前即提示
